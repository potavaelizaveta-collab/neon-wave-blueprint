# NEON WAVE — Blueprint Synth

Rails-проект для Ruby 4.0.7. Дизайн синтезатора выполнен в эстетике технической blueprint/DJ-афиши: синяя сетка, кремовые линии и интерфейс музыкального пульта.

## Запуск
```powershell
bundle install
bundle exec rails server
```
Откройте http://localhost:3000

Основной интерфейс: `app/views/synth/index.html.erb`
