# Sound Sketch

Sound Sketch — интерактивный музыкальный инструмент для создания звуковых зарисовок. Он объединяет два синтезатора, барабаны и четыре эффекта, позволяя постепенно собирать и изменять электронную композицию.

Открыть http://localhost:3000

## Структура файлов и звука

Актуальная версия находится в `public/`: `index.html` — интерфейс, `style.css` — дизайн, `reset.css` — базовый сброс стилей, `script.js` — настройки инструментов, цепочки эффектов, партии и управление.

`roland_tr_909/` содержит три WAV-сэмпла из учебного архива: BT7A0D0.WAV (kick), ST0T3S7.WAV (snare), HHCD6.WAV (hi-hat). Барабаны воспроизводятся через Tone.Sampler. BASS и GLASS созданы через Tone.Synth.

Для каждого инструмента задан объект с настройками synth/sampler, эффектов, channel, sequence и loop. Ноты описаны через time, noteName, duration и velocity. Tone.Part воспроизводит партии, Tone.Transport задаёт общий темп и цикл. Шаги секвенсора включают и выключают события соответствующих партий.

У каждого инструмента своя цепочка Chorus → Distortion → PingPongDelay → JCReverb → Channel. Четыре общих регулятора FX под BASS одновременно изменяют эффекты всех трёх каналов. SOUND управляет общим выходом.

Tone.js 14.8.49 сохранён локально в `vendor/`, лицензия — `vendor/Tone-LICENSE.md`. Приложение не загружает библиотеку с CDN при воспроизведении. Старые учебные прототипы не подключены к основной странице.

## Запуск

Запустить Rails командой `bundle exec rails server` и открыть http://localhost:3000. Можно также обслуживать папку `public/` любым локальным HTTP-сервером; Ruby для самостоятельной HTML-версии не требуется. Для загрузки WAV открывать через HTTP, а не двойным щелчком по HTML.
